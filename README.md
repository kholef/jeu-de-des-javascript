# 🎲 Jeu de Dés JavaScript

## 📌 Présentation

Jeu de dés à deux joueurs réalisé en HTML, CSS et JavaScript.

Le but du jeu est d'atteindre 100 points avant son adversaire.

## 🎮 Fonctionnalités

- 🎲 Lancer le dé
- 👥 Jeu à deux joueurs
- ➕ Gestion des scores
- 🏆 Détection du joueur gagnant
- 🔄 Nouvelle partie
- 🎯 Objectif de 100 points

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript

## 🚀 Utilisation

1. Télécharger ou cloner le projet
2. Ouvrir le fichier `index.html` dans un navigateur
3. Commencer à jouer
